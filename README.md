# Smart Retail Sales Analytics & Business Intelligence Dashboard

An end-to-end analytics project: generate and clean sales data with **Python**, analyse it with **SQL (MySQL)**, and present the results in a **web dashboard (HTML5 + JavaScript)**, **Power BI** and **Tableau**.

> **About the data:** the dataset is **synthetic** (randomly generated by `generate_data.py`) for practice and demonstration. It is not real company data. Messy values (duplicates, missing segments, inconsistent text) are added on purpose so the cleaning step is meaningful.

## Tech Stack
Python (pandas, numpy) | MySQL | Microsoft Excel | Power BI | Tableau | HTML5, CSS3, JavaScript (Chart.js)

## Project Structure
```
generate_data.py        creates data/raw_sales.csv (5,045 raw rows)
clean_and_analyze.py    cleans data, calculates KPIs, writes insights.md and dashboard/data.js
sql/retail_analysis.sql MySQL schema and 8 analysis queries (aggregation, window functions)
dashboard/              web dashboard (open index.html)
data/                   raw_sales.csv, clean_sales.csv
docs/                   Power BI and Tableau build guide
images/                 dashboard screenshots
insights.md             findings generated from the data
```

## How to Run
```bash
pip install -r requirements.txt
python generate_data.py
python clean_and_analyze.py
```
Then open `dashboard/index.html` in a browser. For SQL, run `sql/retail_analysis.sql` in MySQL and import `data/clean_sales.csv`.

## Data Cleaning Steps
- Removed 45 duplicate rows (5,045 to 5,000 records)
- Filled 90 missing customer segments with "Unknown"
- Standardised region text (case and extra spaces)
- Converted dates and added `sales`, `profit`, `month` and `year` columns

## Key Insights
1. Top 3 products (Laptop, Smartphone, Study Desk) generated 74.1% of total sales.
2. Technology has the highest sales (73.5%) but only a 12.49% margin; Office Supplies has the best margin (33.81%).
3. South is the top region by sales (32.7%) and also has the lowest margin (15.34%).
4. Orders with 21-30% discount have a **-10.68%** margin, compared with 21.95% for no discount.
5. October to December contributes 32.0% of sales (festive-season peak).

**Business recommendation:** limit discounts above 20%, since they turn profitable products into loss-making orders.
